# Data change tracker for Silverstripe

Record and track changes and deletes of any dataobjects. View changes/diffs in model admin.

Additionally, track add/remove of items in many_many relationships

## Maintainers

* marcus@symbiote.com.au

## Installation

```sh
composer require symbiote/silverstripe-datachange-tracker:dev-ss6
```

Add a repository entry for this fork:
```json
"repositories": [
    {
        "type": "vcs",
        "url": "https://github.com/nswdpc/silverstripe-datachange-tracker.git"
    }
]
```
